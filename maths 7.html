The Concept of a Set

Well-Defined Collections, Elements, Membership Relations, and Set Notations

1. What is a Set?

📖 Definition: A set is a well-defined collection of distinct objects that share a specified property or rule. The objects belonging to a set are called its elements (or members).
🏫 Classroom Illustration: Imagine a lecture hall of 40 students. If you form a group consisting strictly of "students currently wearing eyeglasses", that collection forms a set because anyone can verify unambiguously whether a given student wears glasses or not.
Well-defined collection: Students in a classroom possessing an identifiable property

Mathematical Example:

\[A = \{2, 4, 6, 8, 10\}\]

  • \(A\) is the label/name of the set.
  • \(2, 4, 6, 8, 10\) are the individual elements (members) of the set.

What Does "Well-Defined" Mean?

A collection is well-defined if there exists an objective criterion that makes it possible to determine conclusively whether any given object belongs to the collection or not.

CollectionIs it a Set?Reasoning
Even integers less than \(10\) Yes Objective: \(\{2, 4, 6, 8\}\) are clearly identifiable.
Students taller than \(180\text{ cm}\) Yes Measurable, objective quantitative criterion.
"Beautiful" students in a class No (Not well-defined) Subjective: beauty depends on personal opinion; no objective rule exists.
Positive integers Yes Objective: \(\{1, 2, 3, 4, \dots\}\) is clearly defined.
⚠️ Exam Trap: A set does not need to be small, finite, or simple. It only needs to be well-defined. Subjective adjectives like "interesting", "difficult", "clever", or "beautiful" never form sets.

2. Elements and Membership Relations

To state whether an object belongs or does not belong to a set, two fundamental relational symbols are used:

\(\in\)
Belongs to / Is an element of

\(x \in A\) asserts that \(x\) is in set \(A\)

\(\notin\)
Does not belong to / Is not an element of

\(x \notin A\) asserts that \(x\) is not in set \(A\)

Application:

Let \(A = \{2, 4, 6, 8, 10\}\). Evaluate the following statements:

  • \(2 \in A\)  →  True (2 is explicitly listed in \(A\)).
  • \(5 \in A\)  →  False (5 is not in \(A\)).
  • \(7 \notin A\)  →  True (7 is indeed not a member of \(A\)).
📌 The Law of Excluded Middle in Set Theory: For any arbitrary object \(x\) and any given set \(A\), exactly one of the following statements is True: \[x \in A \quad \text{or} \quad x \notin A\] They can never be true simultaneously, nor can both be false.

3. Set-Theoretic Notations

Standard mathematical conventions govern how sets and their components are written:

  • Capital Latin letters denote sets: \(A, B, C, X, Y, Z\).
  • Lowercase Latin letters denote individual elements: \(a, b, c, x, y, z\).

Example:

\[B = \{a, b, c, d\}\]

Here, \(B\) is the set identifier, braces \(\{\dots\}\) enclose the collection, and \(a, b, c, d\) are the elements separated by commas.

4. A Set as an Element of Another Set (High Yield)

In set theory, an element inside a set can itself be an entire set. Compare the following two sets carefully:

\[A = \{1, 2, 3\} \quad \text{versus} \quad B = \{1, \{2, 3\}\}\]

Analysis of Set \(A\):

  • Set \(A\) contains three elements: \(1\), \(2\), and \(3\).
  • The cardinality (number of elements) of \(A\) is \(|A| = 3\).

Analysis of Set \(B\):

  • Set \(B\) contains exactly two elements:
    1. The number \(1\)
    2. The set \(\{2, 3\}\) (treated as a single packaged entity)
  • The cardinality of \(B\) is \(|B| = 2\).

Truth Value Verification:

StatementTruth ValueExplanation
\(2 \in A\) True \(2\) is an individual element of \(A\).
\(2 \in B\) False \(2\) is NOT an element of \(B\); only the set \(\{2, 3\}\) is an element.
\(2 \notin B\) True Correct, because \(2\) is not listed on the outer tier of \(B\).
\(\{2, 3\} \in B\) True The whole subset \(\{2, 3\}\) is directly an element of \(B\).

5. Summary Review

  • A set is a well-defined collection of distinct objects.
  • Objects contained within a set are called elements or members.
  • Uppercase letters denote sets (\(A, B\)); lowercase letters denote elements (\(x, y\)).
  • \(\in\) indicates membership ("belongs to"); \(\notin\) indicates non-membership ("does not belong to").
  • An entire set can act as a single element inside another set (e.g., in \(\{1, \{2, 3\}\}\)).
