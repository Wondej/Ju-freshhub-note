Tautology, Contradiction and Contingency

Classification of Compound Propositions by Truth Value Distribution

⚙️ The Output Verification Analogy: Imagine testing an electronic system under every possible input combination. Depending on the final output signal across all tests, the proposition falls into exactly one of three fundamental classifications:
  • Always outputs TRUE → Tautology
  • Always outputs FALSE → Contradiction
  • Outputs a mixture of TRUE and FALSE → Contingency

1. Tautology

📖 Definition: A compound proposition is called a tautology if it is ALWAYS TRUE for all possible truth values of its constituent propositional variables.

Canonical Example: \(p \lor \neg p\)

Read as: "\(p\) OR NOT \(p\)."

\(p\)\(\neg p\)\(p \lor \neg p\)
TFT
FTT

Every single entry in the final column is True. Therefore, \(p \lor \neg p\) is a tautology (often symbolically denoted by \(\mathbf{T}\)).

💡 Intuitive Analogy: "Either the electric lamp is ON, or it is NOT ON." Under the law of excluded middle in classical logic, this compound statement is universally true under every circumstance.

2. Contradiction

📖 Definition: A compound proposition is called a contradiction (or absurdity) if it is ALWAYS FALSE for all possible truth values of its constituent propositional variables.

Canonical Example: \(p \land \neg p\)

Read as: "\(p\) AND NOT \(p\)."

\(p\)\(\neg p\)\(p \land \neg p\)
TFF
FTF

Every single entry in the final column is False. Therefore, \(p \land \neg p\) is a contradiction (often symbolically denoted by \(\mathbf{F}\)).

💡 Intuitive Analogy: "The electric lamp is ON AND the electric lamp is NOT ON" at the exact same moment. Both conditions can never occur simultaneously; it is universally false.

3. Contingency

📖 Definition: A proposition is a contingency if it is neither a tautology nor a contradiction. Its truth value depends (is contingent) upon the truth values of its constituent variables—evaluating to True in some cases and False in others.

Canonical Example: \(p \land q\)

Read as: "\(p\) AND \(q\)."

\(p\)\(q\)\(p \land q\)
TTT
TFF
FTF
FFF

The final column contains both True and False outcomes. Therefore, \(p \land q\) is a contingency.

5. Equivalence via Tautology Criterion

There is a direct mathematical connection between bi-implication and logical equivalence:

\(P \equiv Q \iff (P \leftrightarrow Q)\) is a Tautology

Mathematical Proof of the Principle:

The bi-implication \(P \leftrightarrow Q\) evaluates to True if and only if \(P\) and \(Q\) share the exact same truth value. If \(P \leftrightarrow Q\) is a tautology (True across every single row), then the truth values of \(P\) and \(Q\) match in every row, which is the exact definition of logical equivalence (\(P \equiv Q\)).

📌 Examination Theorem: To prove that two complex propositions \(P\) and \(Q\) are logically equivalent without separate column comparisons, construct the column for \(P \leftrightarrow Q\). If it is a tautology, equivalence is proven.
