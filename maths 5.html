Open Propositions and Quantifiers

Predicates, Universe of Discourse, Quantifier Laws, and Nested Quantifiers

❓ Introductory Question: Is the mathematical expression \(x + 2 = 5\) True or False?
• It is impossible to assign a truth value without knowing what numerical value is assigned to \(x\).
• If \(x = 3\), the sentence evaluates to True (\(3 + 2 = 5\)).
• If \(x = 1\), the sentence evaluates to False (\(1 + 2 = 3 \neq 5\)).

Expressions of this kind form the foundation of predicate logic.

1. Open Propositions (Predicates)

📖 Definition: An open proposition (or predicate) is a declarative sentence containing one or more variables that becomes a true or false proposition only when specific values from a given domain are substituted for the variables.

Predicates are symbolized by a capital letter followed by the variable(s) in parentheses, such as \(P(x)\), \(Q(x, y)\), or \(R(x)\).

Example: \(P(x): x + 2 = 5\)

Value Assigned to \(x\)Substituted Statement \(P(x)\)Truth Value
\(x = 1\)\(1 + 2 = 5\)False
\(x = 2\)\(2 + 2 = 5\)False
\(x = 3\)\(3 + 2 = 5\)True
\(x = 4\)\(4 + 2 = 5\)False

Example: \(P(x): x \text{ is an even integer}\)

  • \(P(2)\): "\(2\) is an even integer" → True
  • \(P(3)\): "\(3\) is an even integer" → False
  • \(P(4)\): "\(4\) is an even integer" → True

Proposition vs. Open Proposition Comparison:

FeatureProposition (Statement)Open Proposition (Predicate)
Truth Status Has a definite, fixed truth value (T or F) Truth value depends on the assigned variable value
Example \(2 + 2 = 4\) (True) \(x + 2 = 4\) (Undetermined until \(x\) is fixed)

2. Universe of Discourse (Domain)

Given an open proposition \(P(x): x > 5\), which values are permissible for substitution?

📖 Definition: The universe of discourse (also termed the universal set or domain, denoted \(U\)) is the set of all allowable values that can be substituted for the variable in an open proposition.

Impact of Domain Selection:

  • Example A — Domain of Natural Numbers (\(\mathbb{N}\)):
    \(U = \{1, 2, 3, 4, 5, 6, \dots\}\)
    For \(P(x): x > 5\), only values \(x \in \{6, 7, 8, \dots\}\) yield True.
  • Example B — Domain of Integers (\(\mathbb{Z}\)):
    \(U = \{\dots, -2, -1, 0, 1, 2, \dots\}\)
    Negative integers, zero, and positive integers are all eligible candidates.
⚠️ Exam Golden Rule: Always identify the specified universe of discourse before evaluating the truth or falsity of a quantified statement. Changing the domain can reverse the truth value!

3. The Two Fundamental Quantifiers

A quantifier binds the variable in an open proposition, transforming it into a complete, testable proposition.

Universal Quantifier (\(\forall\))

Symbol: \(\forall\) ("For all", "For every", "For each")

Asserts that \(P(x)\) is true for every single element in the domain \(U\).

Existential Quantifier (\(\exists\))

Symbol: \(\exists\) ("There exists", "For some", "At least one")

Asserts that \(P(x)\) is true for at least one element in the domain \(U\).

A. Universal Quantifier (\(\forall\)) in Detail

Let \(P(x): x + 0 = x\) with domain \(U = \mathbb{R}\). Since adding zero to any real number leaves it unchanged, the statement holds for every member of the domain:

\(\forall x \in \mathbb{R}, \; x + 0 = x \quad (\text{True})\)

🎓 Institutional Analogy: A university regulation mandates: "Every registered student must possess a student ID card." The rule is universal: if even one student is found without an ID, the universal assertion is broken.

The Counterexample Principle:

To prove that a universal statement \(\forall x \, P(x)\) is False, you only need to produce ONE single counterexample (an element \(a \in U\) for which \(P(a)\) is False).

Disproof Example: Evaluate \(\forall x \in \mathbb{R}, \; x^2 > x\).
• Test the candidate value \(x = 0 \in \mathbb{R}\):
• \(0^2 > 0 \implies 0 > 0 \quad (\text{False}!)\)
• Because \(x = 0\) fails the condition, \(x = 0\) serves as a counterexample.
• Therefore, the universal statement \(\mathbf{\forall x \in \mathbb{R}, \; x^2 > x}\) is conclusively FALSE.

B. Existential Quantifier (\(\exists\)) in Detail

Consider the statement: \(\exists x \in \mathbb{R}, \; x^2 = 9\)

Read as: "There exists a real number \(x\) such that \(x^2 = 9\)."

To prove that an existential statement is True, you only need to demonstrate ONE valid example.

  • Choosing \(x = 3 \in \mathbb{R}\) gives \(3^2 = 9\) (True).
  • Therefore, \(\exists x \in \mathbb{R}, \; x^2 = 9\) is conclusively TRUE.
📌 Verification & Disproof Summary:
• To prove \(\forall x \, P(x)\) True: You must prove it works for every member of \(U\).
• To prove \(\forall x \, P(x)\) False: Provide just one counterexample.
• To prove \(\exists x \, P(x)\) True: Provide just one successful example.
• To prove \(\exists x \, P(x)\) False: You must show that every single member of \(U\) fails.

5. Negation of Quantifiers (De Morgan's Laws for Quantifiers)

When a quantified statement is negated, the quantifier changes type and the inner predicate is negated:

1. Negation of Universal: \(\mathbf{\neg (\forall x \, P(x)) \equiv \exists x \, \neg P(x)}\)

2. Negation of Existential: \(\mathbf{\neg (\exists x \, P(x)) \equiv \forall x \, \neg P(x)}\)

Linguistic and Mathematical Illustrations:

  • Negating "All students passed the examination":
    Original: \(\forall x \, P(x)\) ("Every student passed")
    Negation: \(\exists x \, \neg P(x)\) → "There exists at least one student who did not pass the examination."
  • Negating "Some students passed the examination":
    Original: \(\exists x \, P(x)\) ("Some student passed")
    Negation: \(\forall x \, \neg P(x)\) → "Every student did not pass" (i.e., "No student passed the examination").

Negation of Inequalities:

Consider negating the statement \(\forall x, \; x > 2\):

\(\neg (\forall x, \; x > 2) \equiv \exists x, \; \neg(x > 2) \equiv \mathbf{\exists x, \; x \le 2}\)
🧠 Two-Step Negation Rule:
1. Flip the quantifier: \(\forall\) becomes \(\exists\), and \(\exists\) becomes \(\forall\).
2. Negate the inner open proposition: \(P(x)\) becomes \(\neg P(x)\) (e.g., \(>\) flips to \(\le\), \(=\) flips to \(\neq\)).

6. Nested Quantifiers (Order of Quantifiers Matters!)

When multiple quantifiers are combined in a single statement, their relative order is critical.

Case 1: \(\forall x \exists y, \; x < y\) (over \(\mathbb{R}\))

Read as: "For every real number \(x\), there exists a real number \(y\) such that \(x < y\) (i.e., every real number has a strictly greater number)."

  • Given any choice of \(x\), choose \(y = x + 1\).
  • If \(x = 5\), choose \(y = 6\); if \(x = -10\), choose \(y = -9\); if \(x = 100\), choose \(y = 101\).
  • Since an appropriate \(y\) can always be chosen for any \(x\), the statement is TRUE.

Case 2: \(\exists y \forall x, \; x < y\) (over \(\mathbb{R}\))

Read as: "There exists a single real number \(y\) that is strictly greater than every real number \(x\) simultaneously."

  • Here, a single fixed \(y\) must be chosen first to satisfy all possible real numbers \(x\).
  • If you claim \(y = 1000\), we can immediately pick \(x = 1001\), making \(1001 < 1000\) False.
  • No such universal maximum real number exists. Hence, the statement is FALSE.
Nested ExpressionEnglish InterpretationTruth Status over \(\mathbb{R}\)
\(\forall x \exists y, \; x < y\) Every real number has some number strictly greater than it TRUE
\(\exists y \forall x, \; x < y\) There exists one fixed real number greater than all real numbers FALSE
⭐ Commutativity Rules for Quantifiers:
• Identical quantifiers can be swapped without changing meaning: \(\forall x \forall y \, P(x, y) \equiv \forall y \forall x \, P(x, y)\) and \(\exists x \exists y \, P(x, y) \equiv \exists y \exists x \, P(x, y)\).
• Mixed quantifiers CANNOT be freely interchanged: \(\forall x \exists y \, P(x, y) \not\equiv \exists y \forall x \, P(x, y)\).
